# موقع hsnpmt.com + لوحة التحكم

موقع شخصي احترافي (عربي RTL) مع لوحة تحكم كاملة تعدّل منها كل شي — مبني بـ **PHP + SQLite** عشان يشتغل على أي خطة في Hostinger بدون إعداد قاعدة بيانات.

## الموقع
- بنر رئيسي (عنوان، كلمة ملوّنة، صورتك، أدوات عائمة، أزرار) + شريط إعلان اختياري
- شريط الأرقام والأدوات (48+ مشروع، +2M مشاهدة…) — كل رقم ووصف وأيقونة من اللوحة
- نبذة عني + مهارات + زر «اقرأ القصة كاملة» ← صفحة القصة بخط زمني يمتلئ مع التمرير
- وضع فاتح وداكن مع زر تبديل للزائر (يتذكر اختياره)
- الأعمال: ارفع **فيديو MP4 يشتغل داخل الموقع** مباشرة (أو رابط يوتيوب) + صور ومعرض — وعلى الجوال عملين في كل سطر
- الخدمات · الأعمال (فلترة بالتصنيف + صفحة لكل عمل مع فيديو يوتيوب ومعرض صور)
- البرومبتات (زر نسخ + بحث) · الكتب والمتجر (رابط شراء أو طلب عبر واتساب)
- آراء العملاء · شركاء النجاح (شريط شعارات متحرك) · المدونة · نموذج تواصل
- موشن خفيف وسلس (ظهور عند التمرير، توهّج خلفي هادئ) ويحترم إعداد «تقليل الحركة» — ويمكن إيقافه من الإعدادات
- وضع داكن/فاتح وألوان قابلة للتغيير، متجاوب مع الجوال، SEO وصورة مشاركة

## لوحة التحكم (`/admin`)

## خطوات النشر على Hostinger (وموقعك القديم شغال)

الفكرة: نركّب الموقع الجديد على **رابط مؤقت مخفي** (`new.hsnpmt.com`) وموقعك القديم يبقى شغال، تعبّي البيانات، وفي يوم الإطلاق تنقله مكان القديم.

### المرحلة 1 — تركيب الجديد على رابط مؤقت
1. hPanel ← **Domains ← Subdomains** ← أنشئ `new` (يصير `new.hsnpmt.com`، ومجلده عادة `public_html/new`).
2. hPanel ← **Security ← SSL**: تأكد إن SSL مفعّل لـ `new.hsnpmt.com`.
3. **File Manager** ← افتح مجلد `new` ← ارفع `hsnpmt-website.zip` ← **Extract** ← احذف الـ zip.
4. افتح `new.hsnpmt.com/setup` ← أنشئ حسابك ← **احفظ الرابط السري** (مثل `new.hsnpmt.com/panel-xxxx`).

الموقع الجديد يبدأ في **وضع «قريباً»**: أي أحد يفتح `new.hsnpmt.com` يشوف «قريباً»، وأنت تشوفه كامل.

### المرحلة 2 — التعبئة (براحتك)
احذف المحتوى التجريبي ← الإعدادات ← أضف محتواك ← راجع على الكمبيوتر والجوال.

### المرحلة 3 — يوم الإطلاق (حوالي 10 دقائق)
1. **نسخة احتياطية من القديم**: hPanel ← Files ← Backups (أو حمّل `public_html` من File Manager).
2. في `public_html`: انقل **كل ملفات الموقع القديم** لمجلد اسمه `old-backup` (ما عدا مجلد `new`).
3. افتح مجلد `new` ← حدد **كل شي** (Select all، تأكد إنها تشمل الملفات المخفية `.htaccess` و`.user.ini` ومجلد `data`) ← **Move** إلى `public_html`.
4. افتح `hsnpmt.com/panel-xxxx` (نفس الرابط السري بس على الدومين الرئيسي) ← سجّل دخول ← **«نشر الموقع الآن»**.
5. تأكد إن كل شي تمام، بعدها احذف `old-backup` ومجلد `new` والـ Subdomain.

> لا تحذف مجلدي `data` و`uploads` أبداً — فيهم كل بياناتك وصورك.

## نسيت كلمة المرور؟
1. File Manager ← `public_html/data` ← **New file** باسم `reset-password.txt`.
2. اكتب داخله كلمة المرور الجديدة (8 أحرف أو أكثر) واحفظ.
3. افتح صفحة الدخول (`hsnpmt.com/<الرابط السري>`) — تتعيّن كلمة المرور ويظهر لك اسم المستخدم، والملف ينحذف تلقائياً.

## إضافة حقل جديد
كل الأقسام معرّفة في `includes/schema.php` — أضف حقل هناك ويظهر تلقائياً في اللوحة وتنضاف له خانة في قاعدة البيانات.

## تشغيل محلي

php -S localhost:8000 -t website
