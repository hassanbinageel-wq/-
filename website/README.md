# موقع hsnpmt.com + لوحة التحكم

موقع شخصي احترافي (عربي RTL) مع لوحة تحكم كاملة تعدّل منها كل شي — مبني بـ **PHP + SQLite** عشان يشتغل على أي خطة في Hostinger بدون إعداد قاعدة بيانات.

## الموقع
- بنر رئيسي (عنوان، كلمة ملوّنة، صورتك، أدوات عائمة، أزرار) + شريط إعلان اختياري
- شريط الأرقام والأدوات (48+ مشروع، +2M مشاهدة…) — كل رقم ووصف وأيقونة من اللوحة
- نبذة عني + مهارات + زر «اقرأ القصة كاملة» ← صفحة القصة بخط زمني يمتلئ مع التمرير
- وضع فاتح وداكن مع زر تبديل للزائر (يتذكر اختياره)
- الأعمال: ارفع **فيديو MP4 يشتغل داخل الموقع** مباشرة (أو رابط يوتيوب) + صور ومعرض — وعلى الجوال عملين في كل سطر
- الخدمات · الأعمال (فلترة بالتصنيف + صفحة لكل عمل مع فيديو يوتيوب ومعرض صور)
- البرومبتات (زر نسخ + بحث) · الكتب والمتجر (رابط شراء أو طلب عبر واتساب)
- آراء العملاء · شركاء النجاح (شريط شعارات متحرك) · المدونة · نموذج تواصل
- موشن خفيف وسلس (ظهور عند التمرير، توهّج خلفي هادئ) ويحترم إعداد «تقليل الحركة» — ويمكن إيقافه من الإعدادات
- وضع داكن/فاتح وألوان قابلة للتغيير، متجاوب مع الجوال، SEO وصورة مشاركة

## لوحة التحكم (`/admin`)
الرئيسية · الأعمال · شركاء النجاح · الكتب والمتجر · العملاء · البرومبتات · المدونة · الخدمات · قصتي · الأرقام · الأدوات · التحليلات · التواصل · الإعدادات · الحساب

## الرفع على Hostinger (مرة وحدة)
1. ادخل **hPanel ← Websites ← hsnpmt.com ← File Manager** وافتح مجلد `public_html` (احذف ملف `default.php` إن وجد).
2. ارفع **محتويات** مجلد `website` كاملة داخل `public_html` (يفضّل ترفعها مضغوطة ZIP ثم Extract).
3. من **Advanced ← PHP Configuration** تأكد إن نسخة PHP هي **8.1 أو أحدث**.
4. من **Security ← SSL** فعّل شهادة SSL المجانية.
5. افتح `https://hsnpmt.com/admin` — أول مرة بيطلب منك تنشئ اسم مستخدم وكلمة مرور المدير.
6. ابدأ من **الإعدادات**: اسمك، البنر، النبذة، الواتساب والسوشال، ثم أضف أعمالك.

> المحتوى الموجود أول مرة مجرد أمثلة — عدّله أو احذفه من اللوحة.

**رفع الفيديو:** ملف `.user.ini` يرفع حد الرفع إلى 300 ميجا. إذا ظهر حد أقل في اللوحة، غيّره من hPanel ← PHP Configuration ← `upload_max_filesize`. يفضّل فيديو MP4 مضغوط (أقل من 50 ميجا) عشان يفتح بسرعة.

**النسخ الاحتياطي:** كل بياناتك في مجلد `data` (قاعدة البيانات) و`uploads` (الصور). حمّلهم كل فترة.

**إشعار الرسائل بالإيميل:** يُرسل إلى البريد المكتوب في «الإعدادات ← التواصل». يفضّل تنشئ إيميل على الدومين من Hostinger (مثل `hello@hsnpmt.com`).

## إضافة حقل جديد
كل الأقسام معرّفة في `includes/schema.php` — أضف حقل هناك ويظهر تلقائياً في اللوحة وتنضاف له خانة في قاعدة البيانات.
