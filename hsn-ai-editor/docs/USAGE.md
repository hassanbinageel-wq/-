# أمثلة استخدام · Usage examples

## مونتاج كامل
| الطلب | ما يحدث |
|---|---|
| «هذه كل الخامات الموجودة على التايم لاين أبغاك تشوفها وتمنتجها بأسلوب وثائقي» | قراءة التايم لاين ← تحليل الإطارات والتفريغ ← ملاحظات لكل لقطة ← خطة (افتتاحية/تطور/خاتمة، J/L، Ducking) ← Sequence جديدة |
| «حول هذه الخامات إلى إعلان سينمائي مدته 30 ثانية» | Hook أول ثانيتين، إبراز المنتج وتفاصيله، إيقاع أسرع، مساحة CTA عند الطلب، بدون ادعاءات غير موجودة |
| «شوف المحتوى واقترح له أفضل أسلوب مونتاج ونفذه» | يقترح الأسلوب مع السبب ثم ينفذ (أو يعرض الخطة في وضع المعاينة) |
| «إعلان فاخر بإيقاع هادئ» / «مونتاج عفوي مع الحفاظ على صوت المكان» | يحوّل الوصف إلى قرارات (مدد اللقطات، الانتقالات، الصوت) ويحفظه كأسلوب عند الطلب |
| نطاق «منطقة In/Out» + «منتج هذا الجزء فقط» | يعمل على الأجزاء داخل In/Out |
| تفعيل «حلّل الملفات الأصلية كاملة» | يبحث في الملفات كاملة خارج نقاط القص الحالية |

## تعديلات بالمحادثة
- «البداية بطيئة خلها أقوى» → خطة معدلة تبدأ بأقوى لقطة/جملة.
- «خل أول عشر ثوان بدون كلام» → يُحفظ كقيد `no_speech_before 10` ويُحترم دائماً.
- «ركز أكثر على تفاصيل المنتج» · «قلل الانتقالات» · «خل الإيقاع وثائقي أكثر».
- «احذف اللقطات المتكررة» → مقارنة الملاحظات والإطارات ثم حذف مع Ripple (مع نقطة استعادة).
- «خل صوت المكان أوضح» → رفع Nat sound وتقليل الـ Ducking.
- «اختصره إلى 45 ثانية مع الحفاظ على الفكرة».
- «هذه اللقطة لا تحذفها» (مع تحديدها في التايم لاين) → قيد `keep_source_range`.
- «ثبت البداية وعدل الوسط فقط» → تثبيت أجزاء النسخة الحالية.
- «سو نسخة ثانية مختلفة» · «ارجع للنسخة السابقة».
- «استخدم هذا الجزء من المقابلة كنهاية» → قيد `end_with_source_range`.
- «اشرح قراراتك» → تفسير مختصر لكل قسم.

## خامات ومراجع
- «دور لقطات اليد وهي تمسك المنتج» → بحث في الفهرس ثم تأكيد بصري.
- إرفاق فيديو مرجعي أو رابط: «أبغى مونتاج خاماتي بروح هذا الفيديو، تأثر متوازن» → تحليل الإيقاع ومدد اللقطات والصوت والألوان، ملف أسلوب، ثم خطة مكيّفة لخاماتك.

## صوت وصورة وتسليم
- «نزّل الموسيقى تحت الكلام 15 ديسيبل» · «Fade in ثانيتين للموسيقى» · «نظف صوت المقابلة».
- «طبّق LUT هذا على لقطات الليل» (إرفاق .cube) → تصيير عبر المساعد أو Lumetri.
- «بطّئ اللقطة للنصف» / «Speed ramp عند الحركة» → مقطع جديد مُصيّر.
- «سوّ ترجمة عربية وإنجليزية» → SRT لكل لغة.
- «جهز نسخة رأسية للريلز ومربعة للإنستغرام».
- «صدّر النسخة الأخيرة عبر Media Encoder».
