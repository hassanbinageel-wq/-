# HSN AI Editor — مساعد مونتير ذكي داخل Adobe Premiere

إضافة **UXP** حقيقية لبرنامج Premiere: تفتح اللوحة، تربط Claude، وتتكلم معه بالعربي أو الإنجليزي. المساعد يقرأ المشروع والتايم لاين، يشوف الخامات (إطارات، كلام مفرّغ، صوت)، يقترح بناءً فنياً، **ينفّذ المونتاج فعلياً** على Sequence جديدة، ويستوعب تعديلاتك خلال المحادثة.

| المكوّن | الإصدار |
|---|---|
| Adobe Premiere | **25.6 أو أحدث** (UXP متاح رسمياً من 25.6). يُنصح بـ **26.5** — تفريغ الكلام من داخل Premiere يحتاج 26.5 |
| النظام | macOS و Windows (حسب دعم Premiere) |

## التثبيت والتشغيل

### 1) الإضافة داخل Premiere
**الطريقة المضمونة (للتطوير والاستخدام الشخصي):**
1. ثبّت **Adobe UXP Developer Tool** من تطبيق Creative Cloud.
2. افتح Premiere (25.6+).
3. في UXP Developer Tool: **Add Plugin** ← اختر الملف `hsn-ai-editor/plugin/manifest.json` ← **Load**.
4. في Premiere: **Window ← UXP Plugins ← HSN AI Editor** (أو من قائمة Plugins حسب الإصدار).

**حزمة التثبيت:** الملف الجاهز `release/hsn-ai-editor-0.1.0.ccx`. الحزمة غير موقّعة من Adobe Marketplace؛ إذا رفض Creative Cloud تثبيتها استخدم الطريقة الأولى (UDT) أو اطلب من UDT عمل **Package** على جهازك.

### 2) البناء من المصدر (اختياري — الملف المبني موجود مسبقاً)
```bash
cd hsn-ai-editor
npm install
npm run build      # يبني plugin/dist/main.js
npm run check      # فحص الحزمة و manifest
npm test           # 52 اختبار (محاكاة + ffmpeg حقيقي)
npm run package    # ينتج dist-package/*.ccx و helper zip
```

### 3) المساعد المحلي (اختياري لكن يوسّع القدرات)
يحتاجه: تحليل الصوت (الصمت، LUFS، الضربات)، استخراج إطارات من الملفات الأصلية مباشرة، كشف تغيّر المشاهد، تفريغ الكلام بالعربي عبر Whisper، تحليل الفيديو المرجعي، وتصيير (سرعة/عكس/Speed ramp/LUT/إعادة تأطير/تجميد إطار).
```bash
# ثبّت ffmpeg: macOS: brew install ffmpeg   ·   Windows: winget install ffmpeg
cd hsn-ai-editor/helper
node server.js
```
يطبع **رمز ربط (token)** — الصقه في اللوحة: **الإعدادات ← المساعد المحلي ← رمز الربط**، ثم «اختبار الاتصال».
- يعمل على `127.0.0.1:47631` فقط، ويرفض أي طلب بدون الرمز.
- إذا منع macOS الاتصال عبر http المحلي: ضع مسار **مجلد الجسر** الظاهر في نافذة المساعد (`~/.hsn-ai-editor/bridge`) في إعدادات اللوحة — يتواصلان عبر ملفات بدل الشبكة.

**تفريغ الكلام بالعربي (Whisper):** Premiere لا يدعم العربية في Speech-to-Text حالياً (قائمة لغاته الرسمية لا تتضمن العربية)، لذلك نستخدم Whisper محلياً. عدّل `~/.hsn-ai-editor/helper.json`:
```json
{ "whisper": { "kind": "whisper.cpp", "bin": "/path/to/whisper-cli", "model": "/path/to/ggml-large-v3.bin" } }
```
أو مع `openai-whisper`: `{ "whisper": { "kind": "openai-whisper", "bin": "whisper", "model": "medium" } }`. الصوت لا يغادر جهازك للتفريغ.

**روابط الفيديو المرجعي:** يحمّل المساعد الروابط المباشرة لملفات الفيديو فقط. صفحات مثل YouTube/Instagram لا تُحمّل إلا إذا فعّلت `"allowYtDlp": true` وكان `yt-dlp` مثبتاً — وعلى مسؤوليتك في حقوق الاستخدام. إذا تعذّر الوصول يطلب منك رفع الملف ولا يدّعي تحليله.

### 4) ربط Claude
- **الإعدادات ← ربط Claude**: الصق مفتاح **Anthropic API** (من console.anthropic.com) ← حفظ ← **اختبار الاتصال**.
- المفتاح يُحفظ في **SecureStorage** الخاص بالإضافة (مشفّر بحساب المستخدم) ولا يُكتب في أي ملف، ولا يرسل للمساعد المحلي.
- **اشتراك Claude (Pro/Max) لا يغطي تكلفة API** — الاستخدام يُحاسب على حساب Console. لم أجد مساراً رسمياً موثقاً يسمح لإضافة خارجية بربط حساب Claude (OAuth) واستخدامه بهذا الشكل، لذلك مفتاح API هو المسار المعتمد؛ إذا وفّرت Anthropic ربطاً رسمياً مسموحاً يمكن إضافته في `src/claude/client.js` دون تغيير بقية المشروع. لا نطلب كلمة مرور Claude ولا نقرأ جلسات المتصفح.
- اللوحة تعرض عدد التوكنات والتكلفة التقديرية لكل جلسة (تقدير من الأسعار المنشورة؛ الفاتورة الحقيقية في Console).

## أول استخدام
1. افتح مشروعاً وSequence فيه خاماتك (حتى لو بدون ترتيب).
2. **الإعدادات ← معايرة Premiere ← «تشغيل الاختبار الذاتي»**: يعمل على Sequence مؤقت ويحذفه، ويتأكد من سلوك نسختك في القص والتحريك والصوت والـ Keyframes (أشياء لم يوضحها توثيق Adobe بالكامل).
3. اختر **نطاق العمل**: التايم لاين كامل / المقاطع المحددة / منطقة In-Out / تحديد لوحة Project / كل المشروع — وفعّل «حلّل الملفات الأصلية كاملة» إذا تبغى يبحث خارج نقاط القص الحالية.
4. اختر الوضع: **معاينة الخطة** (افتراضي: يعرض بطاقة الخطة وتضغط «نفّذ») أو **تنفيذ مباشر**.
5. اكتب طلبك.

## الحماية والخصوصية
- المونتاج الشامل يُبنى دائماً في **Sequence جديدة**؛ الـ Sequence الأصلي والملفات لا تُحذف.
- قبل التعديلات المباشرة تُنشأ **نقطة استعادة** (نسخة من الـ Sequence)، وزر «تراجع عن آخر تعديل» يرجعك لها بدون حذف شيء.
- كل خطوة تُنفذ داخل `lockedAccess` + `executeTransaction` باسم واضح، وتُقرأ النتيجة وتُطابق مع المطلوب. فشل خطوة يوقف ما يعتمد عليها فقط.
- زر **إيقاف** يوقف عند أقرب نقطة آمنة؛ إعادة إرسال نفس الخطة لا تكرر التنفيذ (سجل تنفيذ لكل خطة).
- قبل أول رفع لإطارات أو نصوص يُطلب إذنك. ما يُرسل: نص المحادثة، وصف التايم لاين، إطارات مصغّرة، تفريغ الكلام. **لا تُرفع ملفات الفيديو أو الصوت.**
- محتوى الخامات والنصوص والمراجع يعامَل كبيانات للتحليل وليس كتعليمات (مغلّف بعلامة `untrusted_media_data`).
- Claude لا يستطيع تشغيل كود داخل Premiere: فقط أدوات محددة لها مخططات بيانات وتحقق.

## القيود المعروفة
- لا تغيير سرعة أو عكس داخل Premiere عبر الواجهة (البديل: تصيير عبر المساعد، أو Clip › Speed/Duration يدوياً).
- لا قراءة لقفل المسارات، لا حذف مسارات، لا Razor أصلي، لا انتقالات صوتية.
- الترجمة: SRT يُستورد إلى Bin «HSN Captions» وتسحبه للتايم لاين.
- كتابة نص MOGRT تجريبية؛ بدون قالب MOGRT تُضاف Markers «TITLE» مكان العناوين.
- الألوان: Lumetri/LUT تعطي مظهراً تقريبياً، ولا ندّعي مطابقة ألوان دقيقة. معايير الصوت تُقاس (LUFS) ولا تُدّعى بدون قياس.
- تحليل المحتوى يعتمد على عينات إطارات؛ الحركة بين العينات مستنتجة وتُسجل بثقة أقل.
- بعض تفاصيل الواجهة لم يوثقها Adobe بدقة (وحدة مستوى الصوت، مرجع وقت الـ Keyframes، دلالات setStart) — الإضافة تتحقق من النتيجة بعد كل خطوة، والاختبار الذاتي يكشف سلوك نسختك.

## البنية وقابلية التوسع
```
plugin/            ملفات الإضافة (manifest، HTML، CSS، الحزمة المبنية)
src/core           الوقت بالـ ticks والإطارات، مخططات JSON، UTF-8
src/claude         عميل Messages API (بث SSE، أدوات، تفكير، fallbacks، تكلفة)
src/host/premiere  المحوّل الوحيد الذي يلمس واجهة premierepro + الاختبار الذاتي
src/host/mock      محاكاة واجهة premierepro للاختبارات
src/editing        الأساليب، خطة المونتاج (تحقق/توزيع/ترجمة لعمليات)، التحليل، الفهرس، الترجمة
src/executor       منفذ خطوة بخطوة مع إيقاف وسجل وعدم تكرار ومراجعة
src/agent          حلقة المحادثة، سجل الأدوات، الأدوات (قراءة/تخطيط/تعديل/تسليم)، التعليمات
src/storage        الإعدادات، التخزين الآمن للمفتاح، ذاكرة كل مشروع
src/ui             اللوحة
helper/            المساعد المحلي (Node + ffmpeg، بدون مكتبات خارجية)
```
إضافة قدرة جديدة = تعريف أداة واحدة (اسم + وصف + مخطط JSON + دالة) وتسجيلها — Claude يركّب الأدوات بنفسه لطلبات جديدة. إضافة أسلوب = بيانات StyleSpec. التفاصيل في `docs/ARCHITECTURE.md`.

## English summary
**HSN AI Editor** is a real Adobe Premiere **UXP panel** (Premiere 25.6+, recommended 26.5). You connect Claude with an Anthropic API key (stored in UXP SecureStorage), chat in Arabic or English, and the assistant reads the project, analyzes footage (sampled frames, transcripts, audio measurements), proposes a structured edit plan in a chosen or free-described style, and **executes it in Premiere** on a new sequence version — then accepts revisions in conversation (pins, constraints, versions, restore points).

- Install: load `plugin/manifest.json` in **UXP Developer Tool**, or use `release/hsn-ai-editor-0.1.0.ccx`.
- Optional local helper: `node helper/server.js` (ffmpeg; optional Whisper for Arabic transcription). Paste its token in Settings.
- Run **Settings → Premiere calibration → Run self-test** once: it verifies, on a temporary sequence, the host behaviours Adobe's docs leave open.
- Tests: `npm test` → 52/52 passing in simulation + real ffmpeg; **in-Premiere testing must be done on your machine** (`docs/TESTING.md`).
- Known API limits and their alternatives are listed above (speed/reverse via helper renders, fades instead of audio transitions, SRT import for captions, no track-lock getter).
