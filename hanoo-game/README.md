# سباق هنوو

لعبة جري لا نهائي في المتصفح. هنوو يجري، يتفادى العوائق، ويجمع علب الحليب بنكهاتها الأربع.

## التشغيل

افتح `index.html` في المتصفح. لا تحتاج تثبيت أي شيء.

## التحكم

| المفتاح | الوظيفة |
|---|---|
| ↑ | قفز (اضغط مطولاً لقفزة أعلى) |
| ↓ | انحناء على الأرض، أو نزول سريع في الهواء |
| ← → | تحرك يمين ويسار |
| P | إيقاف مؤقت |
| M | الصوت |

## النقاط

كل علبة تعطي 10 نقاط مضروبة في المضاعف. المضاعف يزيد درجة مع كل 5 علب متتالية (حتى ×8)، ويرجع ×1 إذا مرّت ثانيتان بدون علبة أو اصطدم هنوو بعائق.

## العلب الكبيرة

| النكهة | الصديق | القوة |
|---|---|---|
| الفراولة | وردة | سرعة ونقاط ×2 |
| الشوكولاتة | أسمر | درع يحمي من اصطدام واحد |
| الموز | منصور | قفزة أعلى وقفزة مزدوجة |
| المانجو | شمس | مغناطيس يجذب العلب |

عند خط النهاية يتحول هنوو إلى البطل الخارق.
