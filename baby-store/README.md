# متجر «غيمة» لملابس ومستلزمات المواليد

متجر إلكتروني عربي (RTL) كامل مع لوحة تحكم عربية: منتجات وخيارات وباقات هدايا، عرض تفاعلي «على الشماعة»، سلة وطلب كضيف، دفع بالتحويل اليدوي وإرسال السند عبر واتساب، حجز مخزون، تتبع الطلبات، صلاحيات للموظفين، تحكم كامل بالمظهر، ونسخ احتياطي.

> «غيمة» اسم وهوية مؤقتة. غيّر الاسم والشعار والألوان من **لوحة التحكم ← مظهر المتجر** دون تعديل الكود.

---

## التقنيات ولماذا

| الجزء | الاختيار | السبب |
|---|---|---|
| الواجهة والخادم | **Next.js 16 + React 19 + TypeScript** | صفحات تُبنى على الخادم (سرعة وSEO)، وواجهات API في نفس المشروع |
| قاعدة البيانات | **PostgreSQL** — في الإنتاج **Supabase** (مجاني)، ومحلياً **PGlite** المضمّنة | معاملات حقيقية تمنع البيع الزائد عند الطلبات المتزامنة، وتعمل على استضافة سحابية مجانية |
| الصور | **sharp**، وتُحفظ داخل قاعدة البيانات | لا حاجة لخدمة تخزين منفصلة؛ كل صورة يُعاد ترميزها WEBP بعدة مقاسات وتُخزن مؤقتاً في شبكة التوزيع |
| الاستضافة | **Netlify** (مجاني) | الخطة المجانية تسمح بالاستخدام التجاري، ولا تطلب بطاقة ائتمان |
| التحقق | **zod** | كل المدخلات تُتحقق على الخادم |

## النشر المجاني (Netlify + Supabase)

**قاعدة البيانات جاهزة مسبقاً** على Supabase (مشروع `baby-store`، منطقة Ohio ‏us-east-2 بجانب خوادم Netlify):
الجداول، والصفحات والأقسام، والبيانات التجريبية، وحساب المالك. رابط الاتصال (`DATABASE_URL`) وبيانات دخول المالك سُلّمت لصاحب المتجر بشكل خاص — **لا تضعها في المستودع**.

### خطوات النشر (مرة واحدة)

1. ادخل [app.netlify.com](https://app.netlify.com) وسجّل بحساب GitHub (مجاني، بلا بطاقة).
2. **Add new project → Import an existing project → GitHub**، واختر هذا المستودع.
3. في **Branch to deploy** اختر الفرع الذي يحتوي مجلد `baby-store`. باقي الإعدادات تُقرأ تلقائياً من `netlify.toml`.
4. في **Environment variables** أضف متغيراً واحداً: `DATABASE_URL` بالقيمة المسلّمة لك.
5. اضغط **Deploy**. بعد دقيقتين يعمل المتجر على رابط مثل `https://اسم-موقعك.netlify.app` ولوحة التحكم على `/admin`.

يمكن لاحقاً تغيير اسم الموقع من **Site configuration → Change site name**، أو ربط نطاق خاص من **Domain management** (يتطلب شراء نطاق).

### حدود الخطط المجانية (مهم)

- **Netlify**: رصيد 300 وحدة شهرياً (يكفي متجراً صغيراً بآلاف الزيارات). عند تجاوزه **يتوقف الموقع حتى بداية الشهر التالي** دون أي رسوم. تابع الاستهلاك من **Usage** في Netlify.
- **Supabase**: قاعدة بيانات حتى **500 ميجابايت** (تشمل الصور). تعرض لوحة التحكم ← النسخ الاحتياطي المساحة المستخدمة. المشاريع المجانية تتوقف بعد أسبوع بلا نشاط؛ المتجر يمنع ذلك بمهمة مجدولة كل 10 دقائق.
- الخطة المجانية في Supabase **لا تتضمن نسخاً احتياطية تلقائية للمشروع**؛ المتجر يحفظ نسخة يومية من البيانات داخل القاعدة، **ونزّل نسخة أسبوعياً** واحفظها عندك (انظر النسخ الاحتياطي).

## التشغيل المحلي (للتطوير)

المتطلبات: **Node.js 20.9+** (يُفضل 22). لا حاجة لتثبيت قاعدة بيانات.

```bash
cd baby-store
npm ci
npm run db:seed        # اختياري: منتجات وبنرات تجريبية
npm run owner:create   # حساب المالك
npm run dev            # http://localhost:3000  — اللوحة: /admin
```

بدون `DATABASE_URL` تُستخدم قاعدة PGlite داخل `./data`. للاتصال بقاعدة الإنتاج من حاسوبك ضع `DATABASE_URL` في `.env` (بحذر).

عند أول تشغيل تُنشأ تلقائياً صفحات السياسات والأسئلة الشائعة والأقسام الخمسة وتصنيفات العمر والمناسبة (دون منتجات أو بيانات مالية).

## حساب المالك

- **تغيير كلمة المرور**: من لوحة التحكم ← حسابي.
- **نسيت كلمة المرور**: من حاسوبك مع `DATABASE_URL`:
  `npm run owner:create -- --username admin --name "مالك المتجر" --password "كلمة مرور جديدة"`
  (يعيد تعيين كلمة المرور ويُخرج كل الجلسات).
- كلمة المرور 10 أحرف على الأقل وتحتوي حروفاً وأرقاماً. يُقفل الحساب 15 دقيقة بعد 5 محاولات خاطئة.

## قبل الإطلاق (قائمة تظهر أيضاً في الصفحة الرئيسية للوحة)

1. **رقم واتساب الطلبات**: الإعدادات. الافتراضي `+967775038900` (رابط `wa.me/967775038900`).
2. **وسائل التحويل**: لوحة التحكم ← وسائل التحويل. بدونها يرى العميل «تواصل مع المتجر للحصول على بيانات التحويل».
3. **مناطق التوصيل ورسومها**: التوصيل والاستلام (الحالية تجريبية).
4. **المنتجات**: أضف منتجاتك، ثم احذف التجريبية من الإعدادات ← البيانات التجريبية.
5. **صفحات السياسات**: الصفحات والأسئلة (نصوص عامة بلا التزامات).
6. **الشعار والألوان والخط والبنرات**: مظهر المتجر (مسودة ← معاينة ← نشر، مع الرجوع لنسخة سابقة).
7. **قسم «على الشماعة»**: لكل قطعة ملابس ارفع «صورة الشماعة» بخلفية شفافة (PNG) و«صورة الخلف» من صفحة المنتج ← الصور، واختر القطع من مظهر المتجر ← الرئيسية.

## وسائل التحويل

لوحة التحكم ← **وسائل التحويل** ← «إضافة وسيلة»: النوع (بنك / محفظة / صرافة / أخرى)، الاسم، المستفيد، رقم الحساب أو المحفظة، العملة، تعليمات، صورة QR اختيارية، تفعيل/تعطيل وترتيب.
تظهر المفعّلة في صفحة الدفع مع أزرار نسخ. لا يفترض المتجر أن رقم واتساب حساب للتحويل، ولا يحتوي أي بيانات مالية تجريبية.

## الخط (DIN Next LT Arabic)

الخط تجاري ولا يُرفع للمستودع العام. بعد التأكد أن ترخيصك يسمح باستخدامه على الويب:
لوحة التحكم ← **مظهر المتجر ← الألوان والخطوط ← رفع ملف خط**، ثم اختر «الخط المرفوع» وانشر.
إلى ذلك الحين يُستخدم خط «تجوال» (رخصة OFL، مضمّن مع المراعي والقاهرة وIBM Plex Sans Arabic).

## النسخ الاحتياطي والاستعادة

- **تلقائي**: نسخة يومية من البيانات (يُحتفظ بآخر 7) — لوحة التحكم ← النسخ الاحتياطي.
- **يدوي**: «إنشاء نسخة الآن» ثم **تنزيل** الملف (`.json.gz`) واحفظه على حاسوبك أو هاتفك.
- النسخة تضم كل البيانات (المنتجات، الطلبات، العملاء، الإعدادات، المظهر). الصور محفوظة داخل القاعدة نفسها ولا تُضمَّن في الملف.
- **الاستعادة** تتطلب كلمة مرور المالك وكتابة «استعادة»، وتأخذ نسخة أمان قبلها. من سطر الأوامر: `npm run backup` و`npm run restore -- ملف.json.gz`.

## الخدمات الخارجية

- **Netlify** (استضافة) و**Supabase** (قاعدة البيانات) — مجانيتان.
- **واتساب**: روابط `wa.me` فقط؛ لا ربط بـ WhatsApp Business API ولا إرسال تلقائي. العميل يضغط «إرسال» ويرفق السند بنفسه.
- **الدفع**: تحويل يدوي ومراجعة بشرية؛ لا بوابة دفع ولا بطاقات.
- لا بريد إلكتروني ولا رسائل نصية؛ الإشعارات داخل اللوحة. الخطوط مستضافة محلياً.

---

## الأمان باختصار

- كلمات مرور مشفرة (scrypt)، جلسات مجزأة، قفل بعد المحاولات الخاطئة، وحدود طلبات لكل IP.
- الأسعار والخصومات والشحن والمخزون تُحسب على الخادم فقط؛ لا أسرار في الواجهة.
- **سندات التحويل** خاصة: لا تُعرض إلا لمستخدم مخوّل.
- قاعدة البيانات في مخطط خاص (`store`) بدور مستقل، وغير مكشوفة عبر واجهة Supabase العامة.
- رابط التتبع عشوائي ويُخفي البيانات الشخصية جزئياً؛ ملفات CSV محمية من حقن المعادلات.

## بدائل الاستضافة

يعمل المتجر أيضاً على أي خادم Node دائم (`npm ci && npm run build && npm start`) أو عبر Docker (`docker compose up -d --build`) مع `DATABASE_URL` لأي PostgreSQL، أو بدونه (PGlite داخل `DATA_DIR`). المهام الدورية تعمل داخل العملية تلقائياً.
