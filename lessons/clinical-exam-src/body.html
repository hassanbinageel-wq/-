Basic systemic examination

Basic systemic examination is a focused physical examination of a specific body system to identify abnormal signs.

Main systems

Cardiovascular system
Respiratory system
Abdomen / Gastrointestinal system
Neurological system
Musculoskeletal system

Basic examination sequence

For most systems:

STEP 1Inspection
STEP 2Palpation
STEP 3Percussion
STEP 4Auscultation

System 1

Cardiovascular System

InspectionPalpationPercussionAuscultation

Cardiovascular system

Inspection

  • Pallor
  • Cyanosis
  • Edema
  • JVP
  • Precordial pulsations

Palpation

  • Pulse: rate, rhythm, volume
  • Peripheral pulses
  • Capillary refill
  • Apex beat
  • Edema

Cardiovascular system

Percussion

  • Usually not routinely performed
  • May help estimate cardiac borders

Auscultation

  • S1 and S2
  • S3 / S4
  • Murmurs
  • Main valve areas

System 2

Respiratory System

InspectionPalpationPercussionAuscultation

Respiratory system

Inspection

  • Respiratory rate
  • Pattern
  • Chest shape
  • Chest movement
  • Accessory muscle use
  • Cyanosis

Palpation

  • Chest expansion
  • Tracheal position
  • Tactile vocal fremitus

Respiratory system

Percussion

ResonantNormal
DullConsolidation / effusion
Hyper-resonantPneumothorax
Resonant → normal · Dull → consolidation/effusion · Hyperresonant → pneumothorax

Auscultation

  • Breath sounds
  • Wheeze
  • Crackles
  • Bronchial breathing
  • Reduced / absent sounds

  • Liver

Neurological System

InspectionAssessmentReflexes

Neurological system

Inspection

  • Level of consciousness
  • Speech
  • Posture
  • Gait
  • Involuntary movements

Assessment

  • Cranial nerves
  • Muscle power
  • Muscle tone
  • Sensation
  • Coordination
  • Reflexes: deep tendon reflexes
