# استوديو الموشن ديزاين — Opus 5.5

استوديو موشن احترافي يعمل بالكود: تعطيه فكرة، يسألك أسئلة المشروع على مراحل، يقترح ستايلات، ثم يسلّمك
فيديو MP4 جاهز للنشر بصوت مركّب وجهارة مضبوطة — وكل ذلك بالعربي وبطباعة عربية صحيحة.

مبني على منهج كورس **"How to build motion design studio with Opus 5.5 (Full-course)"** لـ
[Movez (@0xMovez)](https://x.com/0xMovez/status/2104216919033192746) (27 سبتمبر 2026)، مع توسيعه للعربية.

```
motion-studio/
  README.md              ← هذا الدليل
  package.json           ← الخطوط العربية + playwright-core
  films/
    nabd-launch/         ← فيلم نموذجي كامل (12 ث، 9:16)
      brief.md · style_guide.md · shotlist.md · film.html · audio.py · nabd-launch.mp4 · out/review_log.md
.claude/skills/motion-studio/   ← المهارة (Claude Code يحمّلها تلقائيًا)
  SKILL.md               ← المسار بـ 12 خطوة
  references/            ← intake · styles · doctrine · arabic-type · sound · critique
  lib/motion.js          ← مكتبة الحركة (سبرينغ، track، كلمات عربية، درزات، كاميرا)
  templates/film.html    ← قالب محايد بلا ستايل
  scripts/               ← new_film.sh · render.mjs · audio_kit.py · mux.py · qc.py
```

### الفكرة المركزية
> **"البرومبت 10٪ من الفيديو، والـ 90٪ الباقية هي الـ harness (المنظومة)."**

أغلب من يجرب الموشن مع Opus 5.5 يحصل على نفس الفيديو: نص في المنتصف فوق تدرّج، كل شيء يتلاشى للداخل، وشعار
في الآخر. السبب ليس ضعف النموذج، بل غياب المنظومة. الكورس يقول إن فيديوهات كانت تكلّفه 1000$+ قبل سنة صار
يصنعها مع Opus 5.5 في أقل من 30 دقيقة، **بدون After Effects**: النموذج يكتب برنامجًا يرسم كل إطار.

### لماذا ينجح هذا؟
- **حتمية = قابلية الإصلاح:** لأن كل إطار دالة في t، أي ملاحظة تُصلح بتعديل + رندر الثواني المتأثرة فقط.
- **النظر = الجودة:** النموذج يرى إطاراته (أوراق تماس، شرائط حول القطعات) فيلتقط ما لا يلتقطه البرومبت.
- **قيود = ذوق:** منع "الافتراضيات" (تدرّج، تلاشي، توهّج) يجبر النموذج على قرارات حقيقية.

## الجزء الثاني: الاستخدام

### المتطلبات (مرة واحدة)
```bash
cd motion-studio && npm i            # الخطوط العربية + playwright-core
pip install numpy scipy pillow       # الصوت وأدوات الفحص
# ffmpeg في PATH، و Chromium (npx playwright-core install chromium أو Chrome مثبت)
```

### الطريقة 1 — داخل Claude Code (الأفضل)
افتح هذا المستودع في Claude Code واكتب أي طلب موشن، مثل:
> سوّ لي فيديو موشن لإطلاق تطبيق توصيل قهوة

المهارة `motion-studio` تتفعّل تلقائيًا، وتمشي بك في:
1. **4 جولات أسئلة** (المشروع → الرسالة → الستايل مع معاينات → المدة والصوت والصيغ)
2. عرض الستايل والشوت ليست للموافقة
3. التنفيذ، ثم النقد على اللقطات، ثم الرندر، ثم الماستر، ثم نقد النهائي
4. تسليم الـ MP4 مع تقرير: المواصفات، ما تغيّر، ما يجب أن تتحقق منه أنت

### الطريقة 2 — يدويًا
```bash
SKILL=.claude/skills/motion-studio
$SKILL/scripts/new_film.sh my-film                  # ينشئ motion-studio/films/my-film/
cd motion-studio/films/my-film
# عدّل brief.md, style_guide.md, shotlist.md, film.html, audio.py
open "film.html?preview"                            # معاينة حية في المتصفح
node ../../../$SKILL/scripts/render.mjs --film film.html --every 0.5          # لقطات للنقد
python3 ../../../$SKILL/scripts/qc.py stills out/stills
python3 audio.py
node ../../../$SKILL/scripts/render.mjs --film film.html --out out/video.mp4 --sub 6
python3 ../../../$SKILL/scripts/mux.py out/video.mp4 out/score.wav my-film.mp4
python3 ../../../$SKILL/scripts/qc.py motion my-film.mp4
```

## الجزء الثالث: الفيلم النموذجي — «نبض»

`films/nabd-launch/nabd-launch.mp4` — إعلان إطلاق لتطبيق عادات **خيالي**، 12 ث، 1080×1920، 30fps.

| الزمن | ما يحدث | الصوت |
|---|---|---|
| 0–2 ث | «كل · يوم · تقول:» كلمة على كل نبضة، والنقطة المرجانية تنبض كقلب | نبض قلب ونقرات فقط |
| 2.0 | **«بكرة.»** تهبط بثقل + اهتزاز | impact |
| 2.75 | خط يشطب «بكرة» من اليمين لليسار | zip |
| 3.0–3.5 | النقطة تكبر حتى تملأ الكادر (zoom-through) ← القطع | riser |
| 3.5–7.5 | أرضية مرجانية، بطاقة «عاداتي اليوم»: 3 صح على الإيقاع، الشريط يمتلئ، العدّاد ٣٠ يومًا، «+١ اليوم» | الموسيقى تدخل، نغمات صاعدة |
| 7.5–7.75 | **فراغ**: سواد وصمت | — |
| 7.75–9.5 | «خلّ · بكرة · **اليوم.**» ضربات | kick+clap ثم impact |
| 9.5–12 | النقطة تعود من اليمين وتصير الشعار «نبض» + CTA | حلّ على C |

**نتائج الفحص (مقاسة):** −14.2 LUFS · −2.3 dBTP · انحراف التمركز −3px · ثبات 29٪ وأطول ثبات 0.5 ث (هدف الهادئ:
≤ 35٪) · المنطقة الآمنة سليمة. سجل النقد الكامل في `films/nabd-launch/out/review_log.md`.
**لم يُسمع الصوت** — قِس فقط؛ اسمعه بسماعات قبل اعتماده.

## البرومبت الرئيسي (لـ claude.ai)

```text
أنت الآن استوديو موشن ديزاين احترافي. تصنع أفلام موشن قصيرة كبرامج: صفحة HTML واحدة فيها
window.renderAt(t) ترسم الإطار الدقيق لأي لحظة t (دالة صافية: لا Math.random، لا مؤقّتات،
لا CSS transitions، لا حالة بين الإطارات)، مع معاينة ?preview تشغّلها بـ requestAnimationFrame.

قبل أي تصميم، استلم المشروع على 4 جولات (اسأل 2–4 أسئلة في كل جولة مع خيارات وتوصية):
(أ) نوع الفيلم، المنصة/الصيغة، الجمهور، الهدف.
(ب) الرسالة الواحدة (اقترح 3 صيغ محددة)، اللهجة، الـ CTA، الأصول المتوفرة.
(ج) الستايل: اقترح 3 ستايلات مختلفة تناسب المنتج، لكل واحد: ألوان بالهكس، خط عربي (Google Fonts)،
    الحركة التوقيعية، 3 لقطات. والخيار الرابع "عندي مرجع". ثم الطاقة: هادئ/متوازن/حماسي.
(د) المدة، الصوت، الصيغ.
إن قلت "قرّر أنت" استخدم: 9:16، 12–15 ث، متوازن، فصحى مبسطة، 120 BPM.

ثم اكتب: brief.md (المنتج وفعله، الرسالة، اختبار الثانية الواحدة بلا صوت، كل رقم ومصدره — لا تخترع أرقامًا)،
style_guide.md (ألوان، خط، مساحة، ملمس، حركة، صوت — خذ قواعد المرجع لا محتواه)،
shotlist.md (جدول على شبكة الإيقاع: الزمن | الصورة | النص | الحركة | الصوت؛ هوك في أول ثانيتين،
شيء جديد كل 2–4 ث، CTA في آخر 3 ث، حركة توقيعية واحدة، وحامل يعبر القطعات). اطلب موافقتي.

قواعد الحركة: سبرينغ بصيغة مغلقة على كل ما يتحرك (snappy 320/30، ui 220/24، base 170/26،
type 150/26 بلا تجاوز، heavy 90/20، playful 260/14)؛ سبرينغ واحد لكل تغيير هدف؛ snap-and-hold
لتغيّر الحالات؛ قانون المتجه في الدرزات (خروج power4In ودخول power4Out، القطع في منتصف الحركة)؛
تيار سائد يمين←يسار؛ للأعلى = خلاصة؛ لا اهتزاز خامل؛ فراغ 0.1–0.5 ث قبل الذروة.
العربية: لا تقسّم الكلمة لحروف أبدًا (يكسر الوصل) — حرّك كلمات، واكشف بقناع من اليمين؛ لا letter-spacing؛
نظام أرقام واحد؛ المنطقة الآمنة 9:16: النص بين y 250 و 1440 ومتمركز على x 540.
ممنوع: عنوان في المنتصف فوق تدرّج، كل شيء يتلاشى، توهّج، جزيئات عامة، crossfade، نفس الانتقال في كل قطع.

الصوت: اكتب audio.py (numpy) يركّب الموسيقى والمؤثرات على نفس الخط الزمني، كل ضربة لها صوت يسبقها بـ 0.03 ث،
الموسيقى تدخل متأخرة، ثم ماستر −14 LUFS تحت −1.5 dBTP. أعطني أوامر الرندر:
Playwright يلتقط renderAt(t) لكل إطار → ffmpeg، مع إطارات فرعية لضبابية الحركة لا تعبر القطعات.

قبل التسليم: انقد نفسك كمخرج قاسٍ في 10 بنود (الهوك، المقروئية، جودة الحركة، الدرزات، التنوع، التكوين،
دقة المنتج، تزامن الصوت، الستايل، سلامة العربية)، أصلح أسوأ 3، ولا تسلّم قبل 8+ في كل بند.
كن صادقًا: قل ما لم تتحقق منه (لم تسمع الصوت، لم ترَ الرندر إن لم تره).
```
