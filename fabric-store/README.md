# 🧵 دفتر الأقمشة — نظام إدارة تجارة الأقمشة الرجالية بالجملة

تطبيق أندرويد (ويعمل أيضًا كتطبيق ويب على الكمبيوتر) بالعربية كاملًا وواجهة من اليمين لليسار، يدير:
الفواتير، العملاء وكشوف الحساب، الدفعات والتحصيل، المديونيات، الأقمشة والمخزون بوحدات متعددة،
المشتريات والموردين، المرتجعات، المصروفات والصندوق، التقارير، المستخدمين والصلاحيات، والنسخ الاحتياطي.

## 📲 تحميل التطبيق (APK)

كل تعديل على مجلد `fabric-store` يبني ملف APK تلقائيًا عبر GitHub Actions وينشره في
**Releases** باسم `fabric-store-v1.0.X` — افتح صفحة Releases في المستودع، وحمّل ملف `.apk` على الجوال وثبّته.

- التحديثات تُثبَّت فوق النسخة السابقة **دون فقدان البيانات** (التطبيق موقّع بمفتاح ثابت `android/app/fabric-store.keystore`).
- أول دخول: المستخدم **المدير** والرمز السري **1234** — غيّره من «الإعدادات ← حسابي».

## 🧮 قواعد الحساب

- صافي الفاتورة = إجمالي الأصناف − الخصومات + الرسوم الإضافية.
- المتبقي من الفاتورة = الصافي − الدفعات المخصصة لها − المرتجعات.
- رصيد العميل = الافتتاحي + الفواتير المعتمدة − كل الدفعات − المرتجعات + المبالغ المردودة نقدًا. (الرصيد السابق يظهر منفصلًا عن الفاتورة الحالية.)
- المخزون يُخزَّن بالوحدة الأساسية (ياردة أو متر) ويُحوَّل من الكرتون/الطاقة بمعاملات كل صنف.
- مجمل الربح = صافي المبيعات − تكلفة البضاعة المباعة؛ صافي الربح = مجمل الربح − المصروفات. التحصيل لا يُحسب إيرادًا جديدًا.
- كل عملية مترابطة (اعتماد فاتورة + خصم المخزون + الدفعة) تُنفَّذ في معاملة واحدة.

## 💾 أين تُحفظ البيانات؟

داخل الجهاز (قاعدة IndexedDB) — يعمل بالكامل دون إنترنت. لنقل البيانات لجهاز آخر أو حمايتها من تعطل الجوال:
**الإعدادات ← تصدير نسخة احتياطية**، ثم على الجهاز الجديد **استيراد نسخة احتياطية**.

## 🛠️ للمطورين

```bash
cd fabric-store
npm install
npm run dev        # تشغيل نسخة الويب
npm test           # اختبارات منطق الحسابات (15 اختبارًا)
npm run e2e        # اختبار المتصفح الكامل (Playwright)
npm run android    # بناء الويب ومزامنة مشروع أندرويد ثم افتح android/ في Android Studio
```

البنية: React + TypeScript + Vite، قاعدة بيانات Dexie (IndexedDB)، Capacitor لأندرويد، jsPDF + html2canvas للـ PDF.
